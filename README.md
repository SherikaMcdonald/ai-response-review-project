# AI Response Review Project

## Overview
This project shows how I evaluate AI-generated responses using a structured review process. I compare outputs based on clarity, accuracy, tone, completeness, and instruction-following. I built this project to reflect my experience in AI response review, prompt evaluation, data annotation, and technical analysis.

## Review Criteria
- Clarity
- Accuracy
- Tone
- Completeness
- Instruction-following
- Safety awareness

## Tools Used
- Markdown
- Excel or Google Sheets
- GitHub

## Why I Built It
I built this project to show a clear and organized approach to reviewing AI outputs. This project reflects the kind of detailed comparison work used in AI training and annotation tasks.

## What I Learned
- How to create a structured scoring guide
- How to compare responses fairly
- How to explain quality differences clearly
- How to document review decisions in a consistent way

## Files Included
- `evaluation-guide.md` for the scoring method
- `sample-prompts.md` for prompt examples
- `response-comparison.md` for side-by-side reviews
- `scoring-sheet.csv` for recorded scores
