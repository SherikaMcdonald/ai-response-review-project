# Evaluation Guide

## Purpose
This guide explains how I review AI responses in a consistent and organized way.

## Scoring Scale
Each category is scored from 1 to 5.

**1** = very weak  
**2** = below expectations  
**3** = acceptable  
**4** = good  
**5** = excellent

## Review Categories

### 1. Clarity
Does the response communicate the answer in a clear and easy-to-follow way?

### 2. Accuracy
Does the response give correct information based on the prompt?

### 3. Tone
Does the response use an appropriate tone for the user and task?

### 4. Completeness
Does the response fully answer the prompt without leaving out important details?

### 5. Instruction-Following
Does the response follow the user’s directions correctly?

### 6. Safety Awareness
Does the response avoid harmful, misleading, or risky content?

## Review Method
I read the prompt first. Then I compare each response against the same categories. After that, I assign scores and explain which response performed better and why.
