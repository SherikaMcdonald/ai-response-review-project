# Response Comparison

## Prompt 1
Write a professional email asking for a deadline extension on a project.

### Response A
Subject: Request for Project Extension

Hello [Manager Name],  
I hope you are doing well. I am writing to request a short extension for the project deadline. I need more time to complete the work carefully and make sure it meets expectations. Thank you for your understanding.

### Response B
Hey, I need more time for the project. I am not done yet. Please extend the deadline.

## Review
Response A is better because it is more professional, more complete, and better suited for a workplace setting. Response B is too brief and informal for the prompt.

## Prompt 2
Explain the difference between a list and a tuple in Python.

### Response A
A list in Python can be changed after it is created. A tuple cannot be changed after it is created. Lists use square brackets, while tuples use parentheses.

### Response B
Lists and tuples are both used to store items. They are mostly the same.

## Review
Response A is better because it is clearer and more accurate. Response B is too vague and does not explain the key difference.
